# Задание: актуальная линейка техники для интернет-магазина (Россия, сегодня 24.10.2026)

Магазин TechAgent продаёт новую электронику в России. Владелец хочет, чтобы в каталоге были только
АКТУАЛЬНЫЕ модели — никакого старья. Цена на сайте = середина (медиана) цен российских магазинов минус 5 %.

## Что такое «актуальная модель»
- Текущее поколение, которое производитель продаёт сейчас (вышло до 24.10.2026, не анонс и не слух).
- Предыдущее поколение — ТОЛЬКО если производитель сам ещё продаёт его официально в своей линейке
  (например, Apple оставляет прошлый iPhone в продаже по сниженной цене). Остатки у перекупов не считаются.
- Не включать: снятые с производства, «только б/у», только китайские версии без глобальной.

## Источники
- Линейка и даты выхода: официальные сайты производителей (apple.com, samsung.com, mi.com, store.google.com,
  dji.com, playstation.com, nintendo.com, dyson.com, sony.com, lg.com и т. п.), их пресс-релизы, крупные
  обзорные сайты (gsmarena, 3dnews, ixbt, the-verge и т. п.).
- Цены: российские магазины — market.yandex.ru, ozon.ru, wildberries.ru, megamarket.ru, dns-shop.ru, mvideo.ru,
  citilink.ru, eldorado.ru, biggeek.ru, re-store.ru, store77.net и т. п. Только новый товар, не б/у.
  Маркет закрыт капчей, DNS отдаёт 401 — бери цены из сниппетов поиска или из biggeek/price.ru (открываются WebFetch).
- Фото: прямая ссылка на картинку (jpg/png/webp) с ОФИЦИАЛЬНОГО сайта производителя или его пресс-центра,
  товар целиком спереди или в 3/4, на белом/прозрачном фоне, без надписей и рекламных плашек, как можно крупнее
  (желательно ≥1000 px). Ссылки на страницы не подходят — нужна ссылка на сам файл картинки. Дай 1–2 варианта.

## Инструменты и лимит
WebSearch (mode "standard") и WebFetch — загрузи их схемы через ToolSearch "select:WebSearch,WebFetch".
Лимит поисков общий на всех помощников: у тебя не больше 28 поисков WebSearch. Экономь: один поиск по линейке
бренда часто даёт все модели сразу; WebFetch не ограничен так жёстко, но не открывай десятки страниц.
Капчи не обходи. Ничего не выдумывай: цены и ссылки — только реально увиденные.

## Результат
Файл JSON (инструмент Write), путь указан в твоём задании. Массив моделей:
```
{
  "brand": "Apple",
  "category": "Смартфоны" | "Планшеты" | "Ноутбуки" | "Наушники" | "Часы" | "Камеры и дроны" | "Игровые консоли" | "Для дома" | "Телевизоры" | "Аксессуары",
  "model": "iPhone 17 Pro",
  "released": "2025-09",
  "status": "current" | "previous_official",
  "specs": {"display": "6.3\"", "chip": "A19 Pro", ...},        // 3–4 ключевых параметра
  "description_ru": "2 предложения по делу: что за устройство и чем выделяется. Без восторгов.",
  "configs": [ {"variant": "256GB", "colors": ["Cosmic Orange", "Deep Blue"], "market_prices": [{"source":"biggeek.ru","price":0,"url":"..."}], "market_median": 0 } ],
  "image_urls": ["https://.../file.png"],
  "note": "что важно знать"
}
```
Конфигурации: 1–3 самых ходовых варианта памяти/размера на модель (не все подряд). Цвета — 1–3 основных.
Если цена конфигурации не нашлась — market_median: null и скажи об этом в note.
Записывай файл постепенно (каждые 4–5 моделей), чтобы работа не пропала.
В конце ответа — короткий список: какие модели включил, какие из нашего старого каталога (если упомянуты в
задании) стоит убрать как устаревшие.
