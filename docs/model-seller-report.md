## Что убрано совсем (мои решения)

- **Калькулятор** `/calculator` — без процента сверху он не нужен; адрес ведёт на `/catalog`.
- **Блог** — все три статьи были про старую модель; адреса ведут на `/how-it-works`.
- **Отзывы** (выдуманные), **тарифы Стандарт/Pro**, **Trade-in** (в нём Партнёр доплачивал за покупателя).
- **Демо-данные** (партнёры, покупатели, заказы, документы кабинета) — только в режиме разработки или
  при сборке с `VITE_DEMO=1`; в боевой сборке их нет.

## Вопросы, которые всплыли по ходу (кроме раздела 6 ТЗ)

1. **Кабинет без бэкенда.** Сайт не связан ни с CRM, ни с банком: анкета Партнёра никуда не уходит, ссылка
   на оплату открывается только в том же браузере, настоящего платежа СБП нет. Нужна связка с CRM
   (её отложили) — или решить, показывать ли кабинет до неё.
2. **«100% оригинал»** на карточке товара — теперь это обещание продавца. Оставляем?
3. **Сроки возврата для покупателя** (7 дней на товар надлежащего качества, 10 дней на возврат денег) взяты из
   российского закона о защите прав потребителей для покупки дистанционным способом. Проверить юристу вместе
   с вопросом о применимом праве.
4. Выдача по доверенности не предусмотрена; отмена оплаченного заказа с возвратом денег в админке не сделана;
   реквизиты после подтверждения Партнёр меняет только через partners@techagent.pro.
